# Quasaria brand assets

- `logo.svg`, `favicon.svg`, `logo-lockup-dark.svg`, `logo-lockup-light.svg`: the **active** concept (see `ACTIVE`).
- `concept-a-*` Singularity Q (default) · `concept-b-*` Beacon · `concept-c-*` Orbit Badge.
- `legacy/`: the v1 illustrative logo.

Swap concepts with `node scripts/render-brand.mjs <a|b|c>` from the repo root; it copies the
SVGs into place and re-renders the favicon/app-icon/OG PNGs. Guide: `docs/THEME.md`.
