# tokens/

- `xlm.svg` — the official Stellar logo symbol (the ring with the two diagonal bars), taken unaltered from the Stellar Development Foundation's
  "Logo Press Kit 2026" published at https://stellar.org/brand-resources (Stellar Logo Final Black, vector). Only the symbol's two paths were kept
  and placed on a white disc so it reads on dark backgrounds. Used only for the native XLM asset (never by ticker alone), per the SDF brand policy
  https://stellar.org/brand-policy ("Building on Stellar"). Stellar is a trademark of the Stellar Development Foundation. Quasaria is independent
  software, not affiliated with, sponsored or endorsed by the Stellar Development Foundation.
- `glacierq-*.png` — the GLACIERQ token icon.
